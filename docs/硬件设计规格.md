## 1. 功能定义

| 功能 | 实现方式 |
|---|---|
| 播放 SD 卡里的 MP3 | ESP32-S3 软解 → I2S → PCM5102A → 3.5mm 耳机 |
| 手机连热点配网 | ESP32-S3 开 SoftAP + 网页，手机填 WiFi 账号密码 |
| 联网下载歌曲到 SD 卡 | ESP32-S3 连家里的 WiFi，HTTP 下载写入 SD |
| 显示 | 0.96" SSD1306 OLED（I2C，复用已有代码） |
| 供电 | 锂电池 + USB-C 充电，USB 插入时优先用 USB |
| 操作 | 3 个按键（上一曲 / 播放暂停 / 下一曲） |

### 4.2 电源部分

#### USB-C 接口

```
USB-C  VBUS (A4/B4/A9/B9) ──┬──► 5V_SYS
                            │
                     D1 (SS34) ──► LDO_IN      ← 防止电池倒灌 USB
                            │
USB-C  GND  (A1/B1/A12/B12) ─┴──► GND

USB-C  CC1 (A5) ──► R8 (5.1kΩ) ──► GND     ⚠️ 必须要有
USB-C  CC2 (B5) ──► R9 (5.1kΩ) ──► GND     ⚠️ 必须要有
USB-C  D-  (A7/B7) ──► ESP32 GPIO19
USB-C  D+  (A6/B6) ──► ESP32 GPIO20
USB-C  SBU1/SBU2 ──► 悬空
```

> **`5.1kΩ` 两个电阻是 USB-C 做受电设备的硬性要求**，少了这两个电阻，很多充电器/电脑不会输出 5V。

#### TP4056 充电电路

```
        ┌──────────────────────┐
 5V ────┤ VCC (4)              │
        │                      │
 电池+ ─┤ BAT (5)       CHRG(7)├── R4(1k) ── D2(红) ── 5V    充电中亮
        │               STDBY(6)├── R5(1k) ── D3(绿) ── 5V    充满亮
        │                      │
        │  TEMP (1) ──┬─ R2(10k) ── 5V
        │             └─ R3(10k) ── GND        ⚠️ 分压到 50%VCC
        │                      │
        │  PROG (2) ── R1(1.2k) ── GND        1A 充电；2.4k = 500mA
        │                      │
        │  CE (8) ──────── 5V                 高电平使能
        │  GND (3) ──────── GND
        └──────────────────────┘
```

**⚠️ 关于 TEMP 脚（这是最容易画错的地方）**

TP4056 的 TEMP 是温度检测输入，会把它的电压和内部 `V_LOW`(≈45% VCC) / `V_HIGH`(≈80% VCC) 比较，超出范围就**暂停充电**。

**所以 TEMP 直接接 GND 会让充电永远不启动**（0V 低于下限，被判为过冷）。

正确做法：用两个 10kΩ 电阻从 5V 分压到 GND，TEMP 接中点 → 约 2.5V = 50% VCC，落在允许区间内。

> 【必须核对 datasheet】你买到的 TP4056 若是兼容型号（如 TP4056-MS），阈值可能略有不同，请对照手册确认 50% 分压在允许区间内。

#### 电源路径 + LDO

```
锂电池 + ────────────────┬──► LDO_IN
                         │
USB 5V ──► D1 (SS34) ────┘
                │
       5V_SYS ─┴── (TP4056 VCC)

LDO_IN ──┬── C2 (100µF) ── GND
         ├── C3 (10µF) ─── GND
         │
    U4 ME6211C33
    ┌────────────────┐
    │ VIN(1)  VOUT(5)├──► 3.3V ──┬── C4 (10µF) ── GND
    │ GND(2)         │           └── 各芯片去耦
    │ EN(3) ── VIN   │
    │ NC(4) ── 悬空  │
    └────────────────┘
```

**为什么这样接**：
- USB 插着时：`LDO_IN` = 5V − 0.3V(肖特基) ≈ 4.7V，高于电池 3.7V，**电池不会放电**，同时 TP4056 在给它充电
- USB 拔掉时：`LDO_IN` = 电池电压 3.7V，LDO 继续供 3.3V
- `C2 (100µF)` 是必须的 —— **USB 插拔瞬间给 LDO 提供缓冲，否则会掉电复位**

#### ⚠️ 3.3V 电流预算（选 LDO 前必看）

| 负载 | 峰值电流 |
|---|---|
| ESP32-S3 模组（Wi-Fi 发射瞬间） | **~350 mA** |
| MicroSD 卡（写入瞬间） | ~100 mA |
| PCM5102A | ~20 mA |
| OLED | ~20 mA |
| **合计峰值** | **≈ 500 mA** |

**所以 ME6211 的 500mA 是卡在边缘的** —— Wi-Fi 发射 + SD 卡同时写入时有掉压风险，表现为随机重启或 SD 卡读写错误。

**建议用 1A 的 LDO**：`RT9080-33GJ5`、`TLV75733`、`SGM2212` 都可以。实在只买得到 ME6211，就把 **C4 加大到 100µF** 缓冲，并且知道这是降级方案。

### 4.3 音频部分（重点）

#### 方案 A（推荐新手）：用 PCM5102A 成品模块

主板上只留 6pin 排针：

```
2.54mm 排针 (6pin)
  1  VIN  ◄── 3.3V
  2  GND  ◄── GND
  3  BCK  ◄── ESP32 GPIO4
  4  LRCK ◄── ESP32 GPIO5
  5  DIN  ◄── ESP32 GPIO6
  6  XSMT ◄── ESP32 GPIO15（可选，直接接 3.3V 也行）
```

**优点**：模块已内含运放/隔直/3.5mm 座，模拟部分全部验证过，你只需要画数字接口。
**代价**：多花 10 元左右，板子上多占 2.5×2cm。

#### 方案 B（进阶）：芯片直焊

```
        ┌─────────────────────────────┐
 3.3V ──┤ DVDD (19)   AVDD (14)       ├── 3.3V
 3.3V ──┤ CPVDD(1)    CPVDD (20)      ├── 3.3V
 GND  ──┤ DGND (18)   AGND (11,17)    ├── GND
        │  CAPP (2) ──┤├── 1µF ── CPVDD   ← 电荷泵电容，漏了 DAC 不工作
        │                             │
 GPIO4 ─┤ BCK  (4)                    │
 GPIO5 ─┤ LRCK (3)                    │
 GPIO6 ─┤ DIN  (5)                    │
 GND  ──┤ SCK  (6)    ← 接地 = 用内部 PLL 从 BCK 恢复时钟
 GND  ──┤ FMT  (7)    ← 接地 = I2S 格式
 GND  ──┤ DEMP (8)    ← 接地 = 关闭去加重
 GND  ──┤ FLT  (9)    ← 接地 = 默认滤波器
GPIO15 ─┤ XSMT (10)   ← 高 = 取消静音
        │                             │
        │ OUTL+ (13) ──► C10 (100µF) ──► 耳机 L
        │ OUTL- (12) ──► 悬空，**不要接 GND**
        │ OUTR+ (15) ──► C11 (100µF) ──► 耳机 R
        │ OUTR- (16) ──► 悬空，**不要接 GND**
        └─────────────────────────────┘
```

**⚠️ 关于 OUTL− / OUTR− 的处理 —— 这里我必须提醒你**

PCM5102A 是**差分输出**。上面这种"只用 OUT+、OUT− 悬空"的接法是一种**简化妥协**：

- ✅ 能出声，而且避免了"把 OUT− 通过电容接地"这个常见错误（那会把交流信号短路，让输出级过载失真）
- ⚠️ 但输出摆幅只剩一半，大音量下失真偏高
- ⚠️ 未使用的输出脚该怎么处理，**必须对照 datasheet 的 Typical Application Circuit 确认**

**正规做法是加运放做差分转单端**（一颗双运放 + 4 个电阻），音质好很多，但对你现在的阶段来说复杂了。

> **我的建议：模拟这部分直接用 PCM5102A 成品模块（方案 A）。** 模块里的运放、隔直、耳机座全部验证过，10 块钱买不到那个省心。你自己画的板子把数字接口和电源做好，音频模块插上去就行 —— 这是工程上正解，不是偷懒。

> 【必须核对 datasheet】上面引脚号是按 TSSOP-20 常见排序写的，**请一定对照你买到的 PCM5102A 手册确认**。CAPP 脚还需要一颗 1µF 电容到 CPVDD，具体值查手册「Typical Application Circuit」。

**关于隔直电容（这条很多人画错）**

PCM5102A 输出有约 1.65V 直流偏置，**不加隔直电容会损坏耳机**。

容值必须够大，否则低频被切掉：

```
截止频率 f = 1 / (2π × R × C)

耳机 32Ω、C = 10µF  → f ≈ 497 Hz    ← 低音全没了，错
耳机 32Ω、C = 100µF → f ≈  50 Hz    ← 可以
耳机 32Ω、C = 220µF → f ≈  23 Hz    ← 更好
```

**所以用 100~220µF，不要用 10µF。**

**关于驱动能力**

PCM5102A 是**线路输出**（2.1Vrms 差分），不是专门的耳机放大器。直推 32Ω 耳机：
- 音量够，但大音量下失真会偏高
- 想更好听，加一颗耳放（如 **TPA6132A2**），或者用方案 A 的模块

### 4.4 MicroSD 卡（SDMMC 1-bit）

```
 3.3V ──┬── 10kΩ ──► DAT0 (上拉，必须)
        └── 10kΩ ──► CMD  (上拉，必须)

TF 卡槽                      ESP32-S3
  CLK   ────────────────────  GPIO7
  CMD   ────────────────────  GPIO8
  DAT0  ────────────────────  GPIO9
  DAT1/DAT2 ─────────────── 悬空（1-bit 模式不用）
  DAT3 (CD) ─────────────── 悬空
  VDD   ──────────────────── 3.3V
  VSS   ──────────────────── GND
```

> **DAT0 和 CMD 的上拉电阻（10kΩ）不能省** —— SD 卡初始化靠这两根线的上拉，省了会出现"卡识别不到"。
>
> 卡座外壳的金属屏蔽脚要接到 GND。

用 **1-bit 模式**的理由：MP3 码率最高 320kbps ≈ 40KB/s，1-bit SDMMC 能到 4~5MB/s，**余量足够**，还省 3 根线。

### 4.5 OLED 显示

```
OLED 模块 (4pin)
  VCC ──► 3.3V（**不要接 5V**）
  GND ──► GND
  SCL ──► ESP32 GPIO11
  SDA ──► ESP32 GPIO10

I2C 上拉：
  SCL ──► 4.7kΩ ──► 3.3V
  SDA ──► 4.7kΩ ──► 3.3V
```

> 多数 0.96" OLED 模块**已经自带 4.7k 上拉**，这时不要再并一组，否则上拉过强反而通信不稳。**看你模块背面有没有 R1~R4 这几个电阻**，有就省掉。

### 4.6 按键

```
 3.3V
   │
  [内部上拉]        ← ESP32 开内部上拉即可，也可外加 10k
   │
   ├──── GPIO12 (上一曲)  ── SW1 ── GND
   ├──── GPIO13 (播放暂停) ── SW2 ── GND
   └──── GPIO14 (下一曲)  ── SW3 ── GND

 EN ──┬── 10kΩ ── 3.3V
      ├── 1µF ─── GND
      └── SW4 ─── GND       复位

 GPIO0 ── 10kΩ ── 3.3V
       └── SW5 ── GND       按住上电进入下载模式
```

> 按键建议加 **100nF 电容到 GND** 做硬件消抖（可选，软件消抖也能解决）。

### 4.7 电池电压检测

```
 电池 + ──┬── R10 (100kΩ) ──┬── ESP32 GPIO1 (ADC1_CH0)
          │                 │
          │              R11 (100kΩ)
          │                 │
          └─────────────────┴── GND
```

- 满电 4.2V → 分压后 2.1V，在 ESP32 ADC 量程内（默认 11dB 衰减约 0~3.1V）✓
- 分压电阻用 100k/100k，静态电流 21µA，对电池影响可忽略
- 想要更准，在 GPIO1 对 GND 加一颗 **100nF** 电容滤波

| 类型 | 线宽 | 说明 |
|---|---|---|
| **普通信号线**（I2C、按键、SD 数据） | **0.2mm (8mil)** | 最细不要低于 0.15mm |
| **I2S 三根线**（BCK/LRCK/DIN） | **0.25mm** | 尽量短，不要跨分割地 |
| **3.3V 主电源** | **0.5mm (20mil)** | 电流约 300mA |
| **电池 / 5V 输入** | **0.6~0.8mm** | 充电电流 1A |
| **USB D+ / D−** | **0.2mm** | 走差分对，等长，尽量短 |
| **地** | 铺铜 | 不用单独画线，底层整片铺 |

### 5.3 间距

| 项目 | 值 |
|---|---|
| 最小线间距 | 0.2mm |
| 最小孔径 | 0.3mm |
| 过孔/焊盘到板边 | ≥0.5mm |

### 5.4 关键走线要求

**I2S 音频线（BCK / LRCK / DIN）**
- 三根线**并排走**，长度尽量一致
- **远离 SD 卡的 CLK**（这是板子上最强的干扰源）
- 不要跨过地平面的裂缝

**SD 卡 CLK**
- 这根线是**抖动/噪声之王**，尽量短
- 两侧用地线包围（包地）
- **绝对不能和 I2S 线平行长距离走**

**USB D+/D−**
- 必须走**差分对**，等长（误差 < 0.5mm）
- 90Ω 差分阻抗（2 层板做不到精确，但尽量靠近）

**电源**
- 3.3V 主干加粗到 0.5mm
- LDO 输出到各芯片的路径要短

**模拟地 / 数字地**
- **2 层板**：整片铺地，不做分割（分割反而容易出问题），靠**布局隔离**代替
- **4 层板**：单独一层地平面，最干净
- PCM5102A 的 AGND 和 DGND **在芯片下方单点连接**，不要连成两个独立的地

## 6. 布局建议（比走线更重要）

### 6.1 分区

```
┌─────────────────────────────────────────────┐
│  ①天线净空区（禁铺铜、禁走线）               │
│  ┌──────────┐                               │
│  │ 模组天线 │                               │
│  └──────────┘                               │
│                                             │
│  ┌────────────────────┐   ┌──────────────┐ │
│  │  ②ESP32-S3 模组    │   │ ⑤SD 卡槽     │ │
│  └────────────────────┘   └──────────────┘ │
│                                             │
│  ┌──────────┐  ┌──────────┐  ┌───────────┐ │
│  │④PCM5102A│  │③电源区   │  │⑥OLED 排针 │ │
│  │ +耳机座 │  │TP4056+LDO│  └───────────┘ │
│  └──────────┘  └──────────┘                │
│                                             │
│  ┌────────────────────────────┐             │
│  │⑦USB-C                      │             │
│  └────────────────────────────┘             │
└─────────────────────────────────────────────┘
```

### 6.2 关键布局原则

1. **天线净空** —— 模组天线一端**必须伸出板边或下方完全禁铺铜**，否则 Wi-Fi 距离严重缩水。这是新手最容易犯的错。

2. **电源区远离音频区** —— TP4056 和 LDO 是发热+开关噪声源，尽量放在板子另一侧。

3. **PCM5102A 靠近耳机座**，音频输出线越短越好。

4. **每个电源脚旁边 0.1µF 去耦** —— 距离芯片电源脚 **< 2mm**，这是硬要求。去耦电容离得远等于没装。

5. **SD 卡槽远离 PCM5102A** —— 卡读写时的电流突变会串进音频。

6. **晶振不用管** —— 模组内部已含，模组下方别走线即可。

7. **USB-C 放在板边**，方便插拔。

8. **电池接口靠近 TP4056**。

### 6.3 去耦电容放置清单

| 芯片 | 去耦电容 | 位置要求 |
|---|---|---|
| ESP32-S3 模组 3V3 | 10µF + 0.1µF | 紧贴 3V3 引脚 |
| PCM5102A DVDD | 0.1µF | 紧贴引脚 |
| PCM5102A AVDD | 0.1µF + 10µF | 紧贴引脚 |
| PCM5102A CPVDD | 0.1µF | 紧贴引脚 |
| TP4056 VCC | 0.1µF | 紧贴引脚 |
| ME6211 输入 | 10µF + 0.1µF | 紧贴引脚 |
| ME6211 输出 | 10µF + 0.1µF | 紧贴引脚 |
| SD 卡座 VDD | 0.1µF + 10µF | 紧贴卡座 |

## 7. 打样前检查清单

画完板子，逐条打勾：

- [ ] USB-C 的 **CC1/CC2 各有一个 5.1kΩ 下拉到 GND**（漏了就不通电）
- [ ] TP4056 的 **TEMP 是分压接法，不是直连 GND**（直连 = 永远不充电）
- [ ] SD 卡的 **DAT0 和 CMD 各有 10kΩ 上拉**
- [ ] 音频输出有 **100µF 以上隔直电容**（漏了 = 烧耳机）
- [ ] 每个 IC 电源脚旁边都有 **0.1µF 去耦**，且距离 < 2mm
- [ ] 模组**天线区域没有铺铜、没有走线、没有过孔**
- [ ] 电池接口**正负极没有画反**（这个错了会冒烟）
- [ ] EN 脚有 **10k 上拉 + 1µF 到地**（否则上电不启动或反复复位）
- [ ] GPIO0 有 **10k 上拉**（否则进不了下载模式）
- [ ] I2S 三根线**没有和 SD CLK 平行走**
- [ ] 电源线宽 ≥ 0.5mm
- [ ] 所有 GND 都连到铺铜（DRC 检查 0 错误）

## 8. 上电调试顺序（很重要，别一次全插上）

1. **先只焊电源部分**（USB-C、TP4056、LDO），不焊模组
   - 插 USB，量 LDO 输出是否为 **3.3V ± 0.1V**
   - 量 TP4056 的 TEMP 脚是否为 **约 2.5V**
   - 不接电池，量电池接口是否有 4.2V 左右

2. **焊 ESP32-S3 模组**，插 USB 看电脑有没有识别到串口/USB 设备
   - 能识别 → 主控正常
   - 不能 → 检查 EN、3.3V、USB 差分对

3. **焊 SD 卡槽**，插卡测试识别

4. **焊 OLED 排针**，接屏测试显示

5. **最后焊音频部分**，用耳机测试（**先放低音量**）
