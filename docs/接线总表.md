# 接线总表（当前实际使用）

> 2026-10-23 整理。硬件已从「OLED」改成「1.3 寸彩屏」，这份是**现在真正在用的接线**，
> 比 `模块拼装方案.md` 新，以这份为准。

---

## 一、ESP32-S3 引脚分配总览

| GPIO | 用途 | 接到哪个模块 |
|---|---|---|
| **4** | I2S BCK（位时钟） | PCM5102A `BCK` |
| **5** | I2S LRCK（左右声道） | PCM5102A `LRCK` |
| **6** | I2S DIN（数据） | PCM5102A `DIN` |
| **7** | 按键 K1（`v` 下） | 屏模块 |
| **8** | 按键 K2（`^` 上） | 屏模块 |
| **9** | 按键 K3（`#` 井） | 屏模块 |
| **10** | SD 片选 CS | MicroSD |
| **11** | SD MOSI | MicroSD |
| **12** | SD SCK | MicroSD |
| **13** | SD MISO | MicroSD |
| **14** | 按键 K4（`*` 星） | 屏模块 |
| **15** | TFT SCL（SPI 时钟） | 屏 |
| **16** | TFT SDA（SPI 数据） | 屏 |
| **17** | TFT RES（复位） | 屏 |
| **18** | TFT DC（数据/命令） | 屏 |
| **21** | TFT BLK（背光） | 屏 |
| **3V3** | 电源 | 所有模块 |
| **GND** | 地 | 所有模块（必须共地） |

> 空闲可用：GPIO 0/1/2/3/19/20/38–48（19/20 是 USB，别占）

## 二、PCM5102A 音频模块（7 根线）

### 右侧一排

| 模块引脚 | 接到 | 说明 |
|---|---|---|
| **VIN** | **3V3** | ⚠️ 不要接 5V |
| **GND** | GND | |
| **BCK** | GPIO4 | |
| **DIN** | GPIO6 | |
| **LRCK** | GPIO5 | |
| **SCK** | **GND** | ⚠️ 主时钟接地，用内部 PLL。**不接就完全没声** |

### 顶排（配置脚）

| 模块引脚 | 接到 | 说明 |
|---|---|---|
| **XSMT** | **3V3** | ⚠️⚠️ 软静音，**低电平=静音**。接错到 GND 就没声音 |
| FLT | 可不接 | 悬空默认低 = 正常滤波 |
| DEMP | 可不接 | 悬空默认低 = 去加重关闭 |
| FMT | 可不接 | 悬空默认低 = **I2S 格式**（正是要的） |
| A3V3 | 3V3 | 可以给 XSMT 取电 |
| AGND | — | 模拟地，可给 FLT/DEMP/FMT 接地用 |
| ROUT / LROUT | 不接 | 耳机走模块上的 3.5mm 座 |

**这一排最容易被忽略的就是 XSMT**——不接或接 GND 都是静音。

## 三、MicroSD 模块（6 根线）

| 模块引脚 | 接到 | 说明 |
|---|---|---|
| VCC | **3V3** | ⚠️ 不要接 5V |
| GND | GND | |
| CS | GPIO10 | |
| MOSI | GPIO11 | 有的模块标 `DI` |
| SCK | GPIO12 | |
| MISO | GPIO13 | 有的模块标 `DO` |

- 卡必须格式化成 **FAT32**
- **SPI2 专用**，不能和屏幕共用（屏幕没有 CS 脚）

## 四、1.3 寸 ST7789 屏 + 4 按键（11 根线）

| 屏引脚 | 接到 | 说明 |
|---|---|---|
| GND | GND | |
| VCC | **3V3** | ⚠️ 不要接 5V |
| SCL | GPIO15 | SPI 时钟（不是 I2C！） |
| SDA | GPIO16 | SPI 数据（不是 I2C！） |
| RES | GPIO17 | |
| DC | GPIO18 | |
| BLK | GPIO21 | 背光，接 3V3 常亮 |
| K4（`*`） | GPIO14 | |
| K3（`#`） | GPIO9 | |
| K2（`^`） | GPIO8 | |
| K1（`v`） | GPIO7 | |

- 驱动 IC：**ST7789**，分辨率 **240×240**，IPS
- ⚠️ **没有 CS 脚**（片选内部拉低），所以必须独占 SPI3，不能和 SD 共用
- 按键另一端在模块内部接地，只需把 K1–K4 接到 GPIO

## 五、电源

| 模块 | 供电 |
|---|---|
| PCM5102A | 3V3 |
| MicroSD | 3V3 |
| 屏 | 3V3 |
| ESP32-S3 | USB 5V 或电池经 IP5306 升压 5V → VIN |

**所有 GND 必须连在一起**。只连一部分会出现各种莫名其妙的问题。

电池方案（IP5306）还没接，现在是 USB 供电。

## 六、易错点（都是踩过的）

| 错误 | 后果 |
|---|---|
| **XSMT 接 GND 或不接** | 静音，接线全对也没声音 |
| **SCK 不接 GND** | 芯片等外部主时钟，完全没声 |
| 把 SCL/SDA 当 I2C 接 | 屏幕不亮 |
| 屏和 SD 共用 SPI 总线 | 花屏（屏没 CS，会收到 SD 的数据） |
| 模块接 5V | 烧 OLED/屏/SD/DAC |
| GND 没全部连通 | 各种随机故障 |
| 屏的两排针插面包板 | 90° 交叉，必然短路 → 用杜邦线 |

## 七、上电自检

烧好固件后上电，屏幕应显示：

```
┌─────────┬─────────┐
│  红色   │  绿色   │
├─────────┼─────────┤
│  蓝色   │  白色   │
└─────────┴─────────┘
```

- 颜色偏差（红蓝互换）→ 改 `tft_display.c` 里的 `rgb_ele_order`
- 黑白颠倒 → 改 `invert_color`
- 全黑没光 → 查 BLK 和 VCC
