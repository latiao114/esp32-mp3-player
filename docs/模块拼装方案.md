## 1. 采购清单：分阶段买，别一次买全

**先花 50 块把「能出声」验证了**，跑通再往上加。别一口气买齐，万一方案要调，钱就白花了。

### 阶段 1：让声音出来（约 50 元）← 先只买这 4 样

| # | 买什么 | 参考价 | 挑选要点 |
|---|---|---|---|
| 1 | **ESP32-S3 开发板** | 30~60 元 | ⚠️ 必须带 **PSRAM**（型号写 N8R2 / N16R8）。推荐 ESP32-S3-DevKitC-1 或带 USB-C 的第三方板 |
| 2 | **PCM5102A 音频模块** | 8~12 元 | 搜「PCM5102 I2S DAC 模块」，要**带 3.5mm 耳机孔**的那种 |
| 3 | **MicroSD 卡模块** | 3~5 元 | SPI 接口，6 个脚（VCC/GND/CS/MOSI/SCK/MISO） |
| 4 | **杜邦线** | 3~5 元 | 买「母对母」**20cm** 一把（约 40 根），别买太长会乱 |

**供电方式**：直接用 USB 线接电脑或者充电头，不需要电池。

### 阶段 2：加显示（0 元）

你手上那个 **0.96" OLED** 直接插上就行，不用再买。

### 阶段 3：做成能带着走（约 25 元）

| # | 买什么 | 参考价 | 挑选要点 |
|---|---|---|---|
| 5 | **IP5306 充电宝模块** | 5~8 元 | 搜「IP5306 移动电源模块」。自带充电 + 5V 升压 + 电量灯 + 保护 |
| 6 | **锂电池** | 10~20 元 | 单节 3.7V，**必须自带保护板** |

### 阶段 4：加按键（1 元，也可以先不买）

| # | 买什么 | 参考价 |
|---|---|---|
| 7 | **轻触开关 ×3** | 1 元 |

先不买也行 —— 调试阶段用串口发命令控制播放，一样能验证功能。

## 2. 接线总表（这张表看完，线就接完了）

### 2.1 引脚分配

| 功能 | ESP32-S3 引脚 | 接到哪个模块的哪个脚 |
|---|---|---|
| I2S 位时钟 | **GPIO4** | PCM5102A → `BCK` |
| I2S 左右声道 | **GPIO5** | PCM5102A → `LRCK` |
| I2S 数据 | **GPIO6** | PCM5102A → `DIN` |
| OLED 数据 | **GPIO8** | OLED → `SDA` |
| OLED 时钟 | **GPIO9** | OLED → `SCL` |
| SD 片选 | **GPIO10** | SD 模块 → `CS` |
| SD 数据出 | **GPIO11** | SD 模块 → `MOSI` |
| SD 时钟 | **GPIO12** | SD 模块 → `SCK` |
| SD 数据入 | **GPIO13** | SD 模块 → `MISO` |
| 上一曲 | **GPIO14** | 开关 1 → 另一头接 GND |
| 播放/暂停 | **GPIO15** | 开关 2 → 另一头接 GND |
| 下一曲 | **GPIO16** | 开关 3 → 另一头接 GND |

### 2.2 电源接线（最容易接错，单独列出来）

| 模块 | VCC 接哪 | GND |
|---|---|---|
| PCM5102A | 开发板 **3V3** | 开发板 GND |
| MicroSD 模块 | 开发板 **3V3** | 开发板 GND |
| OLED | 开发板 **3V3** | 开发板 GND |
| IP5306 模块输出 | 开发板 **5V / VIN** | 开发板 GND |

> ⚠️ **只有 IP5306 接 5V，其他三个统统接 3V3。** 接错 5V 会烧 OLED 和 SD 模块。

### 2.3 电池接线

```
IP5306 模块
  B+  ──►  电池正极（红线）
  B-  ──►  电池负极（黑线）
  USB 口  ◄── 充电时插这里
  OUT+ ──►  开发板 5V
  OUT- ──►  开发板 GND
```

## 4. 几个模块的特殊说明

### 4.1 PCM5102A 模块

不同厂家的模块，引脚名字可能不一样，对照着找：

| 丝印可能写 | 意思 | 接哪 |
|---|---|---|
| `BCK` / `SCK` / `BCLK` | 位时钟 | GPIO4 |
| `LRCK` / `LCK` / `WS` / `DLS` | 左右声道时钟 | GPIO5 |
| `DIN` / `SDI` / `DATA` | 数据 | GPIO6 |
| `VIN` / `VCC` / `3V3` | 电源 | 3V3 |
| `GND` | 地 | GND |
| `SCK`（**另一个**）| 主时钟 | **接 GND** |
| `FMT` | 格式选择 | **接 GND** |
| `XSMT` | 静音 | 接 3V3（常开）或 GPIO15 |

> ⚠️ 有些模块上 `SCK` 出现了两次含义不同：一个是 I2S 的位时钟（接 GPIO4），一个是主时钟 MCLK（接 GND）。**看模块的丝印分组或者商品详情图**，不确定就拍照发我。

### 4.2 MicroSD 模块

- 模块上通常有 **3.3V 稳压 + 电平转换**，所以 `VCC` 接 3V3 没问题
- **不要接 5V**，会烧
- 卡格式化成 **FAT32**

### 4.3 OLED

- 4 个脚：`VCC / GND / SCL / SDA`
- 有的模块标 `GND VCC SCL SDA`，有的标 `GND VCC D0 D1`（D0=SCL, D1=SDA）
- 地址一般是 **0x3C**

### 4.4 IP5306 模块

- 这个模块负责：**充电、升压到 5V、电量指示、电池保护**
- 输出是 **5V**，接开发板的 `5V` 或 `VIN` 脚（开发板自带 LDO 会再降到 3.3V）
- 有些模块**轻载会自动关机**，如果发现供电一会儿就断，按一下模块上的按键唤醒
- 想显示电量：模块上有 4 颗 LED，看灯就行，不用接 ESP32

## 5. 组装顺序（按这个来，出问题好排查）

**第 1 步：只接电源**
```
IP5306 → 开发板 5V/GND
```
插上电池，看开发板电源灯亮不亮、能不能被电脑识别成串口。**不过这一关，别往下接。**

**第 2 步：接 OLED**
```
OLED VCC → 3V3, GND → GND, SDA → GPIO8, SCL → GPIO9
```
烧一个最简单的 I2C 扫描程序，看能不能扫到 0x3C。

**第 3 步：接 SD 卡模块**
```
VCC → 3V3, GND → GND, CS → GPIO10, MOSI → GPIO11, SCK → GPIO12, MISO → GPIO13
```
测试能不能读到卡。

**第 4 步：最后接音频**
```
PCM5102A 按 2.1 接好
```
**接耳机前先把音量调低**。

**第 5 步：接按键**（可选，先用串口命令控制也行）

## 6. 最容易出错的 5 件事

| 错误 | 后果 | 怎么避免 |
|---|---|---|
| 把 5V 接到 OLED/SD/PCM5102A | **烧模块** | 只有 IP5306 接 5V，其余全接 3V3 |
| GND 没全部连在一起 | 各种莫名其妙的问题 | **所有模块的 GND 都要连到开发板 GND**，不能只连一部分 |
| 杜邦线插错一排 | 引脚对不上 | 插之前数一遍，ESP32 板子上有丝印 |
| SD 卡没格式化成 FAT32 | 读不到卡 | 用电脑格式化成 FAT32 |
| 电池没保护板 | 过放会鼓包甚至起火 | **一定买带保护板的电池** |
